### LATENCY-001: 平滑化と体感追従のトレードオフ

- 観察: RTMPose-Mのlive出力でOne Euro OFFは速いが揺れが増え、KalmanもOFFにするとさらに速い。
- ユーザー判定: 両方OFFの遅延は十分許容、Kalmanのみも一応許容。現行One Euroありは遅く感じる。
- 共通条件: IK・床補正・伸展補正・信頼度ゲートあり。One Euro OFF時の代替EMA係数は位置/回転とも1。
- 未確定: 体感遅延のms値、同じ入力のリプレイでの数値順位、数値合格しきい値。
- 評価器へ: 位置/方向追従、静止jitter、振幅抑制、同時刻誤差と欠測を分離する。

### BEND-TWIST-001: 前屈時、つま先は安定して見えるのに腿のひねりが暴れる

- 観察: 今回試した各設定で前屈時に腿トラッカー相当の**ひねりが大きく暴れた**。
  「回転が足りない」ではなく、不安定なねじれとしてユーザーが明確化した。
- ユーザー補足: つま先は揺れていなかった。腿だけが揺れていた。
- 証拠の段階: ユーザーの実機目視。該当区間のraw 3D・回転・confidenceの同期記録は未取得。
  「つま先」がraw点/足tracker/avatarのどの表示段かも未記録で、勝手に確定しない。
- **原因は未確定**。つま先ノイズ、参照方向切替、腰由来の回転補正はいずれも未検証の仮説。
  目視だけから特定処理を原因認定したり、設定を変更したりしない。
- 評価器へ:
  - 腿の向きの変化（swing）と軸まわりのねじれ（twist）を分ける。
  - 左右の腿・足を別々に採点し、全身中央値で腿の異常を隠さない。
  - twist急変/角速度を、同時刻の参照誤差・観測可能性・欠測率と一緒に出す。
  - 全固定なら揺れが消えるが、正しいひねりも消える。動作消失も対照に入れる。
- 人工対照 `forward_bend_fixed_feet`: 上体が前屈し、観測ankle/toe/heelは固定、hip/knee/上体に小ノイズ。
  **実機症状を再現したデータではない**。さらに採点テストでは出力の片腿だけへ既知のtwist振動を
  注入し、足や位置が安定していても検出できることを確認する。
- 実録画の再現・擬似教師作成・原因調査・修正は別段階。現在の状態は「観察記録＋評価テストあり」。
- 2026-09-19 legacy録画2視点pilot: 前屈録画全1186レポートで、左腿45°以上twist stepは
  minimal 8/836、Kalman 7/1153、current 5/1153（有効step分母）。同じ左足では各0。
  左側の出力利用可能数が877/1186と1155/1186で違うため件数だけで順位を付けない。
  区間未ラベルでstartupも含む参照なし診断であり、当日の症状を再現したという判定ではない。

## 評価器を試す対照ケース

| 対照 | 検出したいこと | 誤って通してはいけないもの |
|---|---|---|
| 既知150ms遅延 / 100ms方向遅延 | 位置と方向の追従遅れ | 時間合わせした誤差だけで高評価 |
| 腿だけ±80°のtwist振動、足固定 | 局所的な回転破綻 | 全身中央値や位置誤差だけで見逃し |
| 正しいtwist動作に対し出力を固定 | 動作消失・同時刻誤差 | 急変0を「優秀」と判定 |
| +179°→−179° / q→−q | 短い回転・同じ姿勢として扱う | 358°ジャンプの誤検出 |
| forwardが反対向き / twist参照confidence=0 | 分解未定義 / 参照不明を分離 | 根拠のないtwist正解や誤差0 |
| 欠測・seq穴・人物境界 | jump/rateのsupportを切る | 復帰を1レポートの急回転と誤認 |
